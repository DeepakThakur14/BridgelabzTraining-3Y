Fluid Layouts

A fluid layout uses flexible sizes so the content adapts to different screen widths.

width: 100%;
max-width: 1200px;

Flexible Media

Flexible media allows images and videos to resize within their containers.

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints change the layout when the screen reaches a specific width.

@media (max-width: 600px) {
    ...
}
