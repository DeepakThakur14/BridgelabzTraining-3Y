Responsive CSS Cheat Sheet

Filters

Apply visual effects to images using the filter property.

filter: grayscale(100%);

Media Queries

Change styles according to the screen size.

@media (max-width: 700px)

Responsive Design

Create layouts that work properly on different devices.

width: 100%;

Typography

Use flexible font sizes that adjust with the screen width.

font-size: clamp(1rem, 2vw, 2rem);

CSS Grid

Create responsive rows and columns using Grid.

grid-template-columns: repeat(2, 1fr);

Flexbox

Arrange elements easily in rows or columns.

display: flex;
