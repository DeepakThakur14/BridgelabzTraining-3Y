Responsive Design

Responsive web design allows a website to adapt to different screen sizes and devices. CSS Grid, Flexbox, media queries, relative units and clamp() can be used to create flexible layouts.

A responsive website provides a better user experience on desktops, tablets and mobile devices.

CSS Cheat Sheet

Flexbox

display: flex;

Grid

display: grid;

Media Query

@media (max-width: 700px)

Typography

font-size: clamp();
